# Grace Does Not Cancel Responsibility

A Christian teaching project examining the relationship between grace, repentance, obedience, accountability, and a faithful response to God.

## Live Website
https://brad-hobbswd.github.io/gracedoesntcancelresponse/

## Overview
Grace gives us room to grow, but it does not cancel responsibility. A devotional reflection on grace, consideration, character, and spiritual growth.
